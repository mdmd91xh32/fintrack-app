隱私權政策

更新日期：2026-11-24

適用範圍

FinTrack 是個人自用的記帳工具，只有開發者本人使用，不對外提供服務。本政策說明 FinTrack 如何使用經本人授權取得的 Google 使用者資料。

存取的資料

FinTrack 只申請 Gmail 唯讀權限（gmail.readonly），用來搜尋本人信箱中指定銀行寄出的信用卡電子帳單與轉帳通知，並讀取這些信件的內容與附件。

使用方式

  • 從上述信件解析帳單金額、交易日期與金額，列為待確認，供本人核對後寫入記帳資料。
  • 不寄信，不修改、標記或刪除信件。
  • 不把信件內容送到外部 AI 或其他雲端服務，也不用來訓練 AI 模型。

保存

  • 解析結果只存放在本人自行管理的主機。
  • 不保存原始信件與附件；只保存信件識別碼、處理結果與解析出的帳務資料。
  • Google 授權權杖只存放在該主機的私有設定，不會公開或提供給他人。

分享

FinTrack 不出售、出租或分享 Google 使用者資料，不轉交第三方，也不用於廣告。

FinTrack 使用與傳輸自 Google API 取得之資訊時，遵守 Google API 服務使用者資料政策，包括有限使用（Limited Use）規定。

撤銷授權

可隨時在 Google 帳戶的第三方存取權移除 FinTrack。移除後，FinTrack 立即無法讀取信箱。

聯絡

如有疑問，請透過 GitHub 聯絡開發者。

Privacy Policy (English)

FinTrack is a personal finance tracker used only by its developer and is not offered to the public. It requests only read-only Gmail access (gmail.readonly) to find credit card e-statements and transfer notices from selected banks in the developer's own mailbox.

Parsed amounts and dates are stored only on a server the developer manages, for the developer's own review. Original emails and attachments are not stored. Authorization tokens are kept in that server's private configuration. FinTrack never sends, modifies or deletes email, never sends email content to external AI or other cloud services, and never sells, shares or transfers Google user data to third parties or uses it for advertising.

FinTrack's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time from Google Account third-party access. Contact the developer via GitHub.
